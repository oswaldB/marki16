Je veux **accéder rapidement aux fonctionnalités principales**
Afin de **gagner du temps dans mes tâches quotidiennes**

    Alors je suis redirigé vers la page correspondante

  Scénario: Menu de navigation
    Étant donné que je suis sur le tableau de bord
    Quand j'utilise le menu principal
    Alors je peux accéder à toutes les sections
