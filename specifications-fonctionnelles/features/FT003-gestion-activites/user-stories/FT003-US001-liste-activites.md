# Liste des activités

En tant que **utilisateur**
Je veux **voir la liste de toutes les activités**
Afin de **suivre l'état des opérations**

## Scénarios

  Scénario: Affichage de la liste
    Étant donné que je suis sur la page activités
    Quand la page se charge
    Alors la liste des activités s'affiche
    Et je peux voir les informations de base

  Scénario: Tri et filtrage
    Étant donné que je suis sur la page activités
    Quand je sélectionne un filtre ou un tri
    Alors la liste est mise à jour selon mes critères
