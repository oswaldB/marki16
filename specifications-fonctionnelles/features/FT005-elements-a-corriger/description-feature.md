# Éléments à corriger

- **Objectif** : Centraliser et gérer les éléments nécessitant une correction ou une attention particulière
- **Périmètre** : 
  - Page a-corriger.vue
  - Liste des éléments problématiques
  - Interface de correction
  - Suivi des corrections effectuées
  - Inclut : Identification, classification, résolution des problèmes
  - Exclut : La gestion des impayés (voir FT012)
- **Contraintes** : 
  - Traçabilité des corrections
  - Priorisation des éléments
  - Notification aux responsables
- **Dépendances** : 
  - Toutes les features sources des données à corriger
