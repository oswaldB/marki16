# Liste des éléments à corriger

En tant que **utilisateur**
Je veux **voir la liste des éléments nécessitant une correction**
Afin de **prioriser mes tâches de correction**

## Scénarios

  Scénario: Affichage de la liste
    Étant donné que je suis sur la page "À corriger"
    Quand la page se charge
    Alors la liste des éléments problématiques s'affiche
    Et je peux voir le type et la priorité

  Scénario: Filtre par type
    Étant donné que je suis sur la page "À corriger"
    Quand je sélectionne un type spécifique
    Alors seuls les éléments de ce type s'affichent
