# Gestion des relances

- **Objectif** : Automatiser et suivre le processus de relance des clients
- **Périmètre** : 
  - Page relances.vue
  - Création de campagnes de relance
  - Suivi des relances envoyées
  - Statistiques d'efficacité
  - Inclut : Planification, envoi, suivi
  - Exclut : La gestion manuelle des impayés
- **Contraintes** : 
  - Respect des réglementations (RGPD, etc.)
  - Personnalisation des messages
  - Gestion des canaux (email, SMS, etc.)
- **Dépendances** : 
  - FT010 (Gestion des contacts) pour les destinataires
  - FT012 (Gestion des impayés) pour le déclenchement
  - FT013 (Gestion des séquences) pour l'automatisation
