# Gestion des services

- **Objectif** : Configurer et gérer les services proposés par l'application
- **Périmètre** : 
  - Page services.vue
  - Catalogue des services
  - Tarification
  - Association aux clients
  - Inclut : Création, modification, archivage des services
  - Exclut : La facturation (si applicable)
- **Contraintes** : 
  - Cohérence des prix
  - Historique des modifications
  - Impact sur les contrats existants
- **Dépendances** : 
  - FT010 (Gestion des contacts) pour l'association clients
