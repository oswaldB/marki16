# Séquences de suivi

En tant que **utilisateur**
Je veux **gérer les séquences de suivi client**
Afin de **maintenir une relation proactive**

## Scénarios

  Scénario: Création d'une séquence de suivi
    Étant donné que je veux automatiser le suivi
    Quand je crée une séquence de type "Suivi"
    Alors je peux définir les actions de suivi
    Et leur fréquence

  Scénario: Personnalisation des messages
    Étant donné que j'édite une séquence de suivi
    Quand je modifie les templates de message
    Alors les prochains envois utiliseront les nouveaux templates
